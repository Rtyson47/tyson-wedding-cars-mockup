# Tyson Wedding Cars

The website at https://tysonlimo.co.uk/ (GitHub Pages).

Pages are built from `_src/`: edit `_src/pages/*.html` or the template in `_src/build.py`, then run
`python3 -I _src/build.py` and commit the generated files with the sources. Never edit the
generated `.html` files directly. `_src/` is not published (Jekyll skips underscore folders).
